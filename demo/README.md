# Demo Checker

Hand-written showcase checker that demonstrates trekker library features with fancy terminal output (ASCII banner, progress bars, animated dice roll, colorized tables).

This is **not** a real checker and should **not** be used as a template for new labs. Use `pytrekgen` with a YAML config instead — see `pytrekgen/examples/` and `my_examplario/how_to_make_yoba.md`.

## Running

```bash
just build && STUDENT_ID=test TOKEN=test DEMO_PARAMETER=test ./demo
```

Set `DONT_RUSH_ME=please` to skip the sleep timers.
